# Analyse der gelieferten Designvorlagen

## App-Design

Die Vorlage zeigt eine sehr dunkle Oberfläche mit grünem Neon-Akzent, dünnen grünen Außenlinien, abgerundeten Karten und einer festen linken Navigation. Wichtige visuelle Merkmale wurden übernommen:

- Hintergrund nahezu schwarz / dunkelgrün
- Karten in dunkelblau-grauen Abstufungen
- Grün für positive KPI und primäre Aktionen
- Orange für offene/fehlende Zielwerte
- Sidebar mit aktiver grüner Navigationsfläche
- kompaktes Dashboard mit Wochenplan, KPI-Karten und Schnellaktionen
- KI-Panel als eigene, prominent gestaltete Oberfläche
- große Radien, feine Borders, wenig visuelles Rauschen

Auf Mobilgeräten wird die feste Sidebar durch eine horizontal scrollbare Bottom-Navigation ersetzt.

## Buntewoche

Die zweite Vorlage ist eine Excel-artige Wochenmatrix. Übernommen wurden:

- Montag–Sonntag als Spalten
- Zeitfenster als Zeilen von 08:00 bis 20:00
- farbliche Terminarten
- separater Leistungsbereich unter der Terminmatrix
- Festgebietsumsatz Soll/Ist
- Gesamtumsatz Soll/Ist
- K70-Umsatz pro Tag
- Einheiten pro Tag
- Legende
- PDF-Ausgabe im gleichen Tabellenprinzip

Die App schreibt im Terminraster ausschließlich Termine. Finanz-/Leistungswerte stehen nur im unteren Kennzahlenbereich.
